# CodeAlpha Student Performance Analysis

## Project Overview
This project analyses students' academic performance using the Student Performance Dataset from the UCI Machine Learning Repository.

The project focuses on Exploratory Data Analysis (EDA) and Data Visualization to identify patterns in students' final Mathematics grades.

## Project Objectives
- Analyse students' final Mathematics grades.
- Calculate descriptive statistics.
- Examine study time in relation to academic performance.
- Explore school absences in relation to final grades.
- Present findings using charts.

## Dataset
- Source: UCI Machine Learning Repository
- File: student-mat.csv
- Number of student records: 395
- Number of columns: 33
- Target variable: G3 (final Mathematics grade)

## Tools Used
- Microsoft Excel
- GitHub

## Key Findings
- Average final Mathematics grade: 10.42 out of 20.
- Pass rate (using 10/20 as the pass mark): 67.09%.
- Students who studied for 5–10 hours recorded the highest average grade of 11.40.
- Students with 6–10 days of absence also recorded the highest average grade among the absence groups, at 11.40.

## Project Files
- Dataset: student-mat.csv
- Analysis: Excel workbook containing the analysis and charts.
- Documentation: Project report.

## Conclusion
The project demonstrates how data analysis and visualization can be used to explore student academic performance and identify patterns in educational data.
